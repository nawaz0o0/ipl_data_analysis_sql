# IPL SQL Data Analysis Project

## 📌 About the Project
This is my **first SQL project**, where I analyzed data from the Indian Premier League (IPL). I chose this dataset because I'm familiar with the game and wanted to explore SQL on something I truly enjoy — even though it's not a business-related dataset.

The goal was to practice solving real-world style SQL questions ranging from beginner to intermediate using concepts like:
- Joins  
- Subqueries  
- Aggregations  
- CTEs  
- Window functions  

## 🗂️ Dataset Used
The dataset was downloaded from Kaggle:  
🔗 https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020

It contains two main tables:
- `matches` – match-level data like teams, winner, venue, etc.
- `deliveries` – ball-by-ball data including batsmen, bowlers, runs, etc.


## 🔍 Sample Questions Solved
1. Number of matches each team has played  
2. Top run scorers across all seasons  
3. total number of runs scored by each team in each season.
4. the player with the most number of boundaries (fours + sixes) in a single IPL season.
5. venues where the highest number of matches have been played. 
6. the team that has won the most matches.
7. Match winners when chasing vs defending  
8. Players with most Player of the Match awards  
9. the player who faced the most balls in a single IPL season. 
...and 5+ more covering deeper SQL logic

## 💡 Key Learnings
- Practiced SQL end-to-end on real sports data  
- Built confidence with query structuring and logic  
- Learned how to extract meaningful insights from raw tables
